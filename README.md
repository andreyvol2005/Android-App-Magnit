**Приложение Magnit** разработано в рамках Дипломного проекта в АО «Тандер» и предназначено для демонстрации навыков работы с платформой Android, облачной базой данных Firebase и практиками CI/CD.

## 📱 Основные функции

- **Авторизация и регистрация** — вход по логину и паролю, сохранение сессии на устройстве.
- **Каталог товаров** — просмотр товаров в виде сетки с пагинацией и горизонтальным списком категорий.
- **Расширенная фильтрация** — фильтр по категории, максимальной цене, рейтингу и количеству отзывов.
- **Избранное** — сохранение понравившихся товаров в персональный список.
- **Корзина** — управление количеством товаров, выбор позиций для заказа, динамический пересчет итоговой суммы.
- **Оформление заказа** — выбор способа доставки (самовывоз/курьер) и способа оплаты (онлайн-кошелек/при получении).
- **История заказов** — отслеживание статусов заказов с возможностью отмены и возврата средств.
- **Профиль пользователя** — просмотр баланса, быстрый доступ к избранному и корзине, настройки аккаунта.
